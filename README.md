# nb

nb is a statically typed, natively compiled programming language for expressive, safe, high-performance software.

1. [Overview](docs/overview.md)
2. [Design principles](docs/design.md)
3. [Language reference](docs/language/README.md)
4. [Technical specifications](docs/README.md)
5. [Examples](docs/examples/README.md)

The language reference describes syntax, semantics, examples, and constraints. Independent technical specifications describe memory, the standard library, interoperability, compiler architecture, tooling, and platform integration.

The [task-manager application](examples/task-manager/README.md) includes source files, an illustrative manifest, and a unit test. Example repositories follow the n-os source convention.
