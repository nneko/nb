# Diagnostics

Report source and implementation errors.

## Behaviour

The compiler reports violations of type rules and language constraints. Diagnostic formats are to be defined.

## Specification in development

To be defined: Codes, severity, source ranges, suggestions, stability, machine-readable form, and ownership/error diagnostics.
