# Code generation

Produce native code for supported outputs.

## Behaviour

Code generation supports executables, static libraries, shared libraries, and constrained freestanding targets. Backend selection is to be defined.

## Specification in development

To be defined: Backend selection, target lowering, relocations, ABI integration, debug output, and validation.
