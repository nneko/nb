# I/O

[Standard printing](printing.md) provides print, print_warn, and print_debug. They write to standard streams with separator, terminator, and format options, without requiring a module or object qualifier.

The [Console module](console.md) provides advanced terminal interaction, including colours, cursor control, screen updates, and keyboard input. Its complete API is a specification in development.

## Specification in development

Stream types, input operations, encoding, buffering, partial reads and writes, asynchronous I/O, redirection, and error contracts.
