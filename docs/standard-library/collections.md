# Collections

Library operations on collection types.

## Behaviour

Array, sequence, list, set, map, collection, tuple, and slice have distinct language semantics. Examples demonstrate each, map, push, find, length, and copy. Indexing is bounds-checked.

## Specification in development

To be defined: Method signatures, iteration order, find return contracts, copy depth, hashing/equality requirements, invalidation, and bounds failures.
