# Console

Console is a standard-library module for advanced terminal interaction. Ordinary output uses the global print, print_warn, and print_debug functions.

## Capabilities

Console covers foreground and background colours, text styles, cursor positioning, line and screen clearing, terminal dimensions, resize events, keyboard events, and terminal input modes. It supports interactive layouts and terminal interfaces in the style of a terminal UI library.

The module may contain functions and classes for terminal sessions, screen regions, and other stateful resources. Exact APIs and class structures are specifications in development.

## Specification in development

Capability detection, behaviour for redirected or unsupported terminals, colour representation, cursor operations, keyboard events, input modes, resize delivery, screen updates, terminal-state restoration, cleanup, and platform support.
