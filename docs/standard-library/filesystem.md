# Filesystem

File and filesystem APIs.

## Behaviour

The cleanup example uses File.open, file.read, and file.close with defer. It demonstrates syntax, not complete I/O contracts.

## Specification in development

To be defined: Paths, open modes, ownership, permissions, links, partial reads/writes, platform portability, and failure contracts.
