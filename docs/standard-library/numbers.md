# Numbers

Numeric API contracts.

## Behaviour

Numeric type families are established. Overflow is checked by default; wrapping and saturating mechanisms are intended. Integer division follows integer semantics. Examples show .sqrt() and .to_string().

## Specification in development

To be defined: Numeric API signatures, default widths/representations, arbitrary-precision behavior, decimal contexts, rounding, overflow failure, and wrapping/saturating syntax.
