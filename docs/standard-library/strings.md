# Strings

Unicode string APIs.

## Behaviour

Single- and double-quoted literals represent strings. Interpolation uses \(...). Strings are Unicode-aware. Examples use .length, .empty?, and &:upcase.

## Specification in development

To be defined: Unicode indexing unit, normalization, encodings, slicing, interpolation formatting, quote-specific escape/interpolation behavior, and complete methods.
