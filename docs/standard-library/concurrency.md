# Concurrency

Synchronization and communication APIs.

## Behaviour

The architecture includes channel<T>, mutex<T>, and atomic<T>, alongside async/await and structured concurrency. Intended safety prevents unsynchronized mutable access.

## Specification in development

To be defined: Construction and operations, buffering, lock guards, poisoning if any, atomic memory orders, transfer constraints, cancellation, and target support.
