# Native ABI

Native nb binary execution contracts.

## Behaviour

Native ABI is distinct from the C interoperability boundary. No runtime or ABI is finalized.

## Specification in development

To be defined: Layouts, calling conventions, symbol naming, dispatch, generics, error representation, versioning, and stability. C-facing mappings belong in interoperability/c-abi.md.
