# Testing

Test discovery and execution.

## Behaviour

nbs test runs project tests. The task-manager unit test resides in tests/unit/task-test.nbs and uses assert to check task completion. Test discovery and assertion APIs are specifications in development.

## Specification in development

To be defined: Discovery, test annotations/conventions, isolation, assertions, fixtures, async tests, reporting, and exit codes.
