# Package tooling

Manifest and language-dependency operations.

## Behaviour

nb.toml describes an nb project. nbs init creates a project, and nbs add adds a language dependency. The manifest schema is a specification in development.

## Specification in development

To be defined: Manifest schema, dependency resolution, lockfiles, registries, integrity, publishing, offline behavior, and workspaces.
