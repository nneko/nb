# Lifetimes

Define reference validity and lifetime inference.

## Behaviour

Ownership and borrowing protect access to values throughout their lifetimes. Precise lifetime inference and ownership validity rules are specifications in development.

## Specification in development

To be defined: Lifetime inference constraints, scope boundaries, returned references, closure capture, slice validity, foreign-resource references, and diagnostics.
