# Bindings

Define importing native APIs, exposing nb APIs, and binding generation.

## Behaviour

A dedicated binding specification separates source/API adaptation from ABI and platform execution. No binding generator interface has been specified.

## Specification in development

To be defined: Supported inputs/outputs, naming, public API exposure, type mapping, ownership annotations, generation reproducibility, handwritten overrides, and versioning.
