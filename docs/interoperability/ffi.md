# Foreign function interface

Define foreign declarations, foreign memory access, callbacks, and safety boundaries.

## Behaviour

C interoperability connects nb to native libraries. Explicit unsafe scopes delimit low-level memory operations.

## Specification in development

To be defined: Declaration syntax, library loading, pointer conversion, ownership transfer, callback lifetimes/threading, error mapping, unwinding, and safe-wrapper obligations.
